## Описание работы модуля Б(2)
	
	1. Запуск из корневой директории chvt2026_Shilov_Nikita_9

	2. Запуск скрипта на проезд вперед/назад:  Python3 module2/module2.py / Python3 module2/module2back.py

	4. При запуске консоль будет ожидать проездной путь в секундах(написать только цифру)

	3. В консоль выведется что миссия началась и ровер проедет на n/a кол-во метров

	4. После того как ровер проедет указанное кол-во метров, выведется надпись в консоль, что миссия завершена

## Описание работы модуля В(3)
	
	1. Запуск из корневой директории chvt2026_Shilov_Nikita_9

	2. Запуск скрипта на попытку детекта с камеры роборуки Python3 module3/module3.py

	3. В консоль выведется что миссия началась и роборука на RMC1 начнет попытку схвата детали

	4. после запуска скрипта, в консоли будет запрос какую деталь взять(пример запроса: "введите одну из трех деталей: Brash, Knive, pliers")

    5. после отправки запроса, роборука найдет деталь и поднимает ее, после чего положит на обратное место

	6. После того как положит деталь, миссия завершится и в консоль выведется: mission_finished

## Описание работы модуля Г(4)
	
	1. Для Запуска Веб-сервера вам понадобится Bun(https://bun.sh/), установка: "curl -fsSL https://bun.sh/install | bash" (Также можно использовать node.js(npm/pnpm) для запуска)

	2. Запуск веб-сервера из chvt2026_Shilov_Nikita_9: cd module4/RMC_Panel/ && bun run dev

	3. Для запуска Бекенд сервера вам понадобится Python пакет "Flask" (https://flask.palletsprojects.com/en/stable/)
	
	4. нужно создать окружение для flask из chvt2026_Shilov_Nikita_9: python3 -m venv .venv

	5. когда появится в консоли (.venv), значит вы уже в окружение, теперь настройка: pip install flask

	6. дальше запуск самого бекенд сервера из chvt2026_Shilov_Nikita_9: python3 module4/RMC_Panel/src/backend/api.py

	7. Дальше можете заходить на веб панель на: http://localhost:5173/

	Функционал: 
		Реализованы кнопки движения вперед и Экстренная кнопка сброса скорости(движения)

## Описание работы модуля Д(5)

	1. Для запуска решения из chvt2026_Shilov_Nikita_9: cd module5/ && python3 module5.py

	2. При запуске скрипта, РМС2 будет двигаться вперед до тех пор пока не дойдет до поворота

	3. После чего РМК2 попытается повернуться и заехать под стелаж

	4. Дальше РМК1 будет ехать вперед пока не доедет до точки поворота и повернет
	
	5. После чего РМК1 Начнет сближение со стелажом

	6. После того как РМК1 доедет до стелажа он подождет 3 секнуды и будет возвращаться обратно в старотовую точку

	7. После того как РМК1 вернется, РМК2 начнем свое движение обратно на стартовую точку

	8. Когда оба РМК вернутся на стартовые точки миссия заершится

	9. Также если при каких то обстоятельствах РМК1 и РМК2 не сможет повернуть, они оба вернуться обратно на стартовые точки и миссия завершится.
