## Описание работы модуля B(2)
	
<details>
	
	1. Запуск из корневой директории chvt2026_Shilov_Nikita_9

	2. Запуск скрипта на проезд вперед/назад:  Python3 module2/module2.py / Python3 module2/module2back.py

	4. При запуске консоль будет ожидать проездной путь в секундах(написать только цифру)

	3. В консоль выведется что миссия началась и ровер проедет на n/a кол-во метров

	4. После того как ровер проедет указанное кол-во метров, выведется надпись в консоль, что миссия завершена

## Описание работы модуля V(3)

<details>
	
	1. Запуск из корневой директории chvt2026_Shilov_Nikita_9

	2. Запуск скрипта на попытку детекта с камеры роборуки Python3 module3/module3.py

	3. В консоль выведется что миссия началась и роборука на RMC1 начнет попытку схвата детали

	4. после запуска скрипта, в консоли будет запрос какую деталь взять(пример запроса: "введите одну из трех деталей: Brash, Knive, pliers")

    5. после отправки запроса, роборука найдет деталь и поднимает ее, после чего положит на обратное место

	6. После того как положит деталь, миссия завершится и в консоль выведется: mission_finished
